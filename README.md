# Entrevista de Emprego — Preparação profissional

Site educacional, formal e monocromático. Inclui fundamentos de recrutamento, roteiro de simulação, funções de entrevista, competências (CHA), banco de perguntas comentadas, cronômetro, rubrica de observação, exercício prático e checklist.

**Cenário:** vaga hipotética de Assistente Administrativo Júnior em empresa fictícia. Não é anúncio de vaga real, nem representa aprovação ou avaliação de um candidato real.

## GitHub Pages
Ative em Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Privacidade
Anotações, notas e checklists são armazenados somente no navegador da pessoa. A exportação gera um `.txt` local. O site não coleta dados em servidor.

## Integração Abalion

Este site inclui `assets/abalion-bridge.js`, que lê `abalion/sections.json` e exibe novas páginas criadas via central Abalion (depois da implantação do GitHub Actions e GitHub Pages). O catálogo está vazio por padrão; nenhuma alteração remota ocorre sem confirmação autorizada.
